# Космический инвентарный автобаттлер (рабочее название)

Подробный дизайн: @docs/GDD.md

## Контекст

- Автор — опытный TS/React-разработчик. Основы не объяснять.
- Общение на русском, кратко и по делу. Код, идентификаторы и коммиты — на английском.
- Цели: сделать небольшую законченную игру, которой можно похвастаться и выложить на itch.io / Яндекс Игры (позже Steam); прокачать визуал и эффекты (PixiJS, шейдеры, частицы).
- Главный риск — раздувание объёма. Предыдущий, более крупный проект был брошен. Любую новую механику сверять со скоупом MVP в GDD.

## Стек

- Vite + React + TypeScript (strict)
- PixiJS — сцена боя и эффекты
- Framer Motion — анимации UI (магазин, раскладка)
- Vitest — тесты
- Состояние, пакетный менеджер и прочие мелочи — предложить и согласовать

## Архитектура

- `src/engine/` — чистый TS без зависимостей от DOM/React/Pixi. Детерминированная симуляция боя на тиках, seeded RNG. Вход: два корабля + seed. Выход: лог событий.
- `src/content/` — данные: модули, корабли, враги (типизированные константы). Все баланс-числа живут здесь.
- `src/ui/` — React: магазин, сетка корпуса, drag&drop, меню.
- `src/battle/` — PixiJS: проигрывание лога событий с анимациями.
- Движок никогда не импортирует из `ui/` и `battle/`. Визуал только читает лог.

## Правила работы

- Маленькие инкременты, после каждого шага — рабочее состояние.
- Движок покрыт тестами: одинаковый seed → одинаковый лог.
- Перед крупным архитектурным решением — предложить варианты и спросить.
